# 阅接力 · 公共图书馆图书共读Agent
> 项目：阅接力 | 参赛：ACC 2026 Time to Build 黑客松 Agent赛道
> 开发：学生团队，基于HTML网页Demo + 智能体交互，适配北京市一卡通阅享证（少儿阅享证/成人阅享证）

## 📖 项目简介
北京公共图书馆有海量免费图书资源，凭**阅享证（一卡通）**可以通借通还：
- 少儿阅享证（18周岁以下）：一次最多借30册，首借28天，最多续借3次，每次续14天，最长可借70天，免押金
- 成人阅享证（13周岁以上）：一次最多借40册
一个家庭2位成人+1名孩子，单次一共可以借阅110本图书；一学期借阅2次，合计220本。
按图书单价30元估算，一个家庭一学期可以节约购书成本6600元。
一个班级36名同学一起参与，可以最大化利用公共图书馆资源，减少重复买书，推动班级共读、图书流转接力。

阅接力Agent，就是帮助家庭、班级管理图书馆借阅图书、规划阅读、接力流转图书的智能助手。
功能定位：**不做图书交易、不私自倒卖图书，只做公益共读流转、借阅提醒、阅读计划、图书台账管理**，合规使用北京公共图书馆通借通还政策。

## ✨ 核心功能
1. 📚 借阅规则查询：一键查询北京一卡通阅享证借阅、续借、期限规则
2. 📅 借阅到期提醒：录入借书日期，自动计算到期日、可续借时间
3. 📋 图书台账登记：录入书名、借阅人、归还时间、接力下一位同学
4. 📖 共读计划生成：给班级/家庭生成阅读清单、分阶段阅读任务
5. 🤝 图书接力流转：记录图书在同学之间传递状态，追踪流转去向
6. 📊 节约成本统计：自动统计一共省下多少购书费用
7. 💬 自然语言对话：用口语提问，智能体给出方案（网页端交互Demo）

## 🧱 技术方案
- 前端Demo：原生HTML单页网页，无需服务器，本地直接打开、离线可用
- 智能体逻辑：可对接Coze（扣子）Agent，也可独立网页运行
- 部署方式：GitHub Pages / Gitee Pages，拿到公开在线链接，适合黑客松现场演示
- 无后端数据库：Demo版本数据保存在浏览器本地存储，简单轻量化，适合参赛Demo
